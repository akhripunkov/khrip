# Задачи на PostgreSQL под нагрузкой (v0.12)

`eval/perf.sh ledger shop tracker`, три прогона подряд; в таблицах — прогон с медианой запросов в секунду для каждой пары задача/язык. Сервер на 2 ядрах, `wrk` (64 соединения) на 2 других, PostgreSQL 16 на той же машине без привязки к ядрам.
