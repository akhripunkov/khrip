# Токены: стоимость задачи со скиллом (v0.13)

Считают `bench/tokens/skill.mjs` (стоимость со скиллом) и `bench/tokens/eval.mjs`
(размер решений); `bench/tokens/run.sh` печатает обе таблицы. Решения — код без
комментариев, скилл — весь текст файлов, как его читает модель.

## Как считается

Решение владельца (docs/design/v0.13-status.md, «Khrip доучивается скиллом»):
модель всегда работает со скиллом Khrip, и правило 2 меряется так, как работает
агент со скиллом:

    стоимость задачи = w × ядро скилла + прочитанные главы + программа

- **ядро** — `skill/khrip/SKILL.md` целиком; оно в system prompt и кэшируется:
  w = 0,02 (цена прочитанного из кэша токена prompt относительно выходного);
  рядом — w = 0,2 (prompt без кэша);
- **главы** — полным весом, как будто их пишут, а не читают: это верхняя
  граница (на деле глава — входные токены, без кэша — вес 0,2). Строка «главы как
  prompt» — та же стоимость с весом w у глав;
- **какие главы читает модель:** задачи на PostgreSQL — `postgresql.md`,
  остальные — ни одной. Так и было в пробном прогоне (bench/results/2026-10-28-tokens-part2.md):
  ledger прочитал `postgresql.md`, notes и inventory — ничего;
- **Go, C# и Python** модель знает: их спецификация пуста, стоимость — сама
  программа (однострочное правило языка из eval/PROMPT.md — меньше 30 токенов,
  при w = 0,02 это меньше одного токена);
- **прежний способ** (до скилла): весь `docs/KHRIP.md` в prompt, w × KHRIP.md +
  программа.

Это стоимость **одного правильного ответа**, без неудачных попыток. Настоящая
метрика — токены на решённую задачу в слепой проверке (eval/README.md,
«Протокол слепой проверки»): там же попытки и сообщения о неудаче.

В скобках — во сколько раз дороже, чем Khrip (меньше 1 — Khrip дороже). Ядро —
2973 токена, `postgresql.md` — 887, весь KHRIP.md — 4456.

Что это значит, честно:

- **С кэшем (w = 0,02) и без базы** Khrip дешевле всех: ядро добавляет к задаче
  59 токенов, и запас программ (Python длиннее на 4–9 %) его покрывает. Прежний
  способ (весь KHRIP.md в кэше) — на 3–5 % дороже: ядро меньше справочника.
- **На PostgreSQL глава решает исход.** 887 токенов главы полным весом больше,
  чем Khrip выигрывает у Python в программе (в среднем 532 на задачу): по формуле
  владельца Khrip на задачах с базой дороже Python (×0,82) и почти равен C#
  (×1,05), а по всем 11 задачам дороже Python (×0,93). Если глава — входные
  токены (вес w, как у ядра), Khrip впереди всех: ×1,31 к Python на базе, ×1,18 по
  всем задачам. Варианты для решения владельца: считать главы как prompt;
  сжать `postgresql.md` до того, что нужно типичной задаче (≈ 400 токенов,
  остальное — во вторую главу); перенести основу `sql` в ядро.
- **Без кэша (w = 0,2)** ядро стоит 595 токенов на задачу — больше большинства
  программ: Khrip дороже Python и C# во всех группах и наравне с Go.
- Это стоимость одного правильного ответа. Попытки меняют картину сильнее:
  в пробном прогоне ledger занял 4 попытки (7190 токенов при w = 0,02 против
  1941 по этой таблице). Решение даёт только слепая проверка с долей решённых
  задач и токенами на решённую задачу.
