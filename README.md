# Khrip

> **K**eep **H**ardware **R**unning **I**n **P**arallel

Компилируемый язык для HTTP API под Linux x86-64. Две цели:

1. **API быстрее, чем на Go и C#:** больше запросов в секунду, ниже задержка p99,
   меньше памяти.
2. **Удобство для нейросетей:** модель, у которой в контексте только спецификация
   Khrip, пишет работающий API не хуже, чем на Go и C#.

Обе цели проверяются замерами, а не заявлениями.

| | |
|---|---|
| Компилятор | `khc` |
| Исходники | `.kh` |
| Платформа | Linux x86-64, статический ELF без libc |
| Статус | **v0.1**: компилятор на Khrip собирает сам себя |

## Сборка из исходников

Нужны только `nasm` и `ld`: никаких Go, C или других компиляторов.

```
./build.sh       # зерно на ассемблере → khc → khc собирает сам себя
tests/run.sh     # тесты
```

Компилятор `khc` написан на Khrip ([src/khc.kh](src/khc.kh), ~1600 строк). Первый раз его
собирает зерно на ассемблере x86-64 ([bootstrap/khc0.asm](bootstrap/khc0.asm)), дальше он
собирает себя сам. Два последних поколения совпадают побайтно. Самокомпиляция занимает
около 4 мс, компилятор весит 38 КБ.

```khrip
fn main() -> i64 {
    println("Hello, Khrip!")
    return 0
}
```

```
build/khc -o hello lib/std.kh hello.kh && ./hello
```

Сейчас язык — минимальное подмножество [Khrip-0](docs/KHRIP0.md): целые числа, функции,
циклы, строки, системные вызовы Linux.

## Каким будет API

```khrip
type User {
    id: i64
    name: str
}

route GET "/users/{id}" (id: i64) -> 200 User | 404 {
    let user = users.get(id) else {
        return 404
    }
    return 200 user
}
```

Маршрутизацию, проверку входных данных, JSON и описание OpenAPI компилятор генерирует
сам из объявления `route`. Подробности в [docs/DESIGN.md](docs/DESIGN.md), план
в [docs/ROADMAP.md](docs/ROADMAP.md).

## Эталон: Go и C#

Цифры, которые Khrip должен обогнать. Идиоматичные серверы без экзотических настроек:
[bench/go](bench/go), [bench/csharp](bench/csharp).

Сервер на 2 ядрах, нагрузка `wrk` с двух других ядер, 128 соединений
([полный отчёт](bench/results/2026-10-19.md)):

| Сервер | plaintext RPS | p99, мс | json RPS | p99, мс | Память, МБ | Старт, мс |
|---|---:|---:|---:|---:|---:|---:|
| Go 1.24 net/http | 75 864 | 9.01 | 70 715 | 6.99 | 14 | 13 |
| C# .NET 10 ASP.NET Core (JIT) | 113 674 | 6.80 | 111 704 | 4.59 | 96 | 370 |
| C# .NET 10 ASP.NET Core (Native AOT) | 113 184 | 3.75 | 105 238 | 9.10 | 38 | 42 |

**Планка для Khrip:** больше ~114 тыс. запросов в секунду (уровень C#), меньше 14 МБ
памяти и старт быстрее 13 мс (уровень Go). p99 в одиночном прогоне сильно шумит,
поэтому сравнивать по нему будем на нескольких прогонах.

Повторить замер: `bench/run.sh` (нужны Go, .NET SDK 10 и `wrk`).
